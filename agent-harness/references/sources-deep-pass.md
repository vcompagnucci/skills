## Resolved conflicts

- **Retrying after streaming.** OpenAI's Agents SDK no-retry rule (2026-03-12) gave way to Anthropic's recovery by stage (late September 2026). Text already delivered through a channel still can't be rewound.
- **Switching models.** "Never switch the model inside one conversation" gave way to one model by default with switches at a turn boundary where the cache is already lost or under persistent overload: OpenAI's errors guide, Anthropic's preserved thinking, Factory, Cognition and LangChain.
- **Step limit.** A final call with tools switched off (Anthropic, Microsoft) comes first; the application fallback covers its failure.
- **Smaller corrections.**
  - GPT-6 changes effort in-band without a cache break (OpenAI, 2026-10-02). Compact at the end of a turn, not when the customer returns (Anthropic, 2026-09-24).
  - "Forget that" removes every version. Declared note relations come before the date tiebreak.
  - Only ADK 1.x and LangGraph re-run a paused step. Only OpenAI's Agents API keeps subagents away from function tools. A self-hosted sandbox doesn't keep the conversation inside.
  - Anthropic outranks a research paper on running state-changing calls one at a time. Factory's validator-first rule (2026-08-27) is newer than Anthropic's 2026-01-23 post, for large back-office tasks only.
