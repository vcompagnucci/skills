# Glossary

Every term the claude.dev posts coin or use in their own sense, in alphabetical order.

- **Adversarial verification.** A separate agent checks each agent's output against a rubric. (`workflows`)
- **Agentic laziness.** Claude stops a long multi-part task early and calls it done after partial progress. (`workflows`)
- **Cache-safe forking.** A side computation (compaction, summarization, skill execution) runs with the parent's exact prefix so it hits the cache. (`caching`)
- **Classify-and-act.** A classifier agent routes a task to different agents, or classifies the output at the end. (`workflows`)
- **Compaction buffer.** Context space held back for the compaction prompt and the summary it produces. (`caching`)
- **Context engineering.** Assembling everything Claude receives besides your prompt: system prompt, skills, CLAUDE.md, memory, references. (`ctx-eng`)
- **Dynamic workflow.** A multi-agent script Claude writes for one task, in JS with `agent()`, `parallel()`, and `pipeline()`. (`workflows`)
- **Effort.** How much compute you want spent. It mostly changes thinking, and with it how much Claude verifies and decides on its own. (`effort`)
- **Effort curve.** Score against tokens across one model's effort levels. (`effort`)
- **Effort ladder.** Running a hard task at medium and then high, and a mechanical task at low, to find the right level. (`cost`)
- **Elicitation.** The model asking the user questions. (`seeing`)
- **Fan-out-and-synthesize.** One agent per step, each in a clean context, then a step that waits for all of them and merges their outputs. (`workflows`)
- **Finish line.** The explicit "done means..." condition in a task prompt. (`opus-5-5`)
- **Generate-and-filter.** Generate many ideas, filter them by rubric or test, and drop duplicates. (`workflows`)
- **Goal drift.** Claude slowly loses the original objective across turns, especially after compaction drops details. (`workflows`)
- **Gotchas section.** The list of known failure points in a skill, grown from real failures. The posts call it the highest-signal part of a skill. (`skills`)
- **Hill climbing.** Driving a metric down step by step once Claude can measure it. (`faster`)
- **HTML maximalist.** Thariq's name for himself: he stopped using Markdown for almost everything. (`html`)
- **Loop until done.** Keep spawning agents until a stop condition is met, instead of running a fixed number of passes. (`workflows`)
- **Numbers demon.** How engineer Shelley Vohr described the model during the performance sprint. (`faster`)
- **On-demand hooks.** Hooks a skill turns on only while it's invoked, for that session (`/careful`, `/freeze`). (`skills`)
- **Opusplan.** A model alias where Opus plans in plan mode and Sonnet carries out the plan. (`cost`)
- **Progressive disclosure.** The agent loads context as it needs it: skill files that point to other files, deferred tools, subagents. (`seeing`, `ctx-eng`)
- **Quarantine.** Agents that read untrusted content get no privileges. The agent that acts only sees their summaries. (`workflows`)
- **Railroading.** Spelling out every step in a reusable skill so Claude can't adapt it. (`skills`)
- **Ratchet.** A CI benchmark ceiling that can only go down, lowered automatically when the count improves. (`faster`)
- **Rich references.** Detailed inputs (HTML artifacts, test suites, code to port, rubrics) that replace plain markdown specs. (`ctx-eng`)
- **Rulebook-style work.** Operations-type tasks where more effort barely helps (12% to 22%). (`effort`)
- **Seeing like an agent.** Designing tools from the model's point of view, by reading its outputs. (`seeing`)
- **Self-preferential bias.** Claude prefers its own results when it verifies or judges them. (`workflows`)
- **Static composer.** An HTML copy of the input box built into the page, so users can type before React starts. (`faster`)
- **Throwaway editor.** A one-off HTML file for one piece of data, ending in an export button. (`html`)
- **Tournament.** N agents try the same task in different ways, and pairwise judging picks a winner. (`workflows`)
- **ultracode.** The trigger word that makes Claude Code build a dynamic workflow. (`workflows`)
- **Undertriggering.** A skill runs less often than expected. Logging usage finds it. (`skills`)
- **Unhobbling.** Removing constraints that older models needed. (`ctx-eng`)
