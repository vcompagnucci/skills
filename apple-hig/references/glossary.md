# Glossary

Apple's named concepts and terms of art for iPhone, iPad, and Mac, 503 terms, alphabetical. Each line is defined by the page that discusses the term most, and lists every page that defines it. Grep for a term instead of reading this file whole.

- **Accent color** — the app's brand color as applied in the interface; reserve it for primary actions and status indicators. (`branding`)
- **Accent color (macOS)** — an app-specified color for buttons, selection highlighting, and sidebar icons, shown only when the system accent setting is multicolor. (`color`)
- **Accessibility labels / accessibility elements** — labels that describe a chart's values and components, and elements that help people interact with the chart. (`charting-data`)
- **Accessibility Nutrition Labels** — App Store labels that communicate how accessible an app is. (`accessibility`)
- **Accessory view** — a custom view appended to a macOS or visionOS alert to provide additional information. (`alerts`)
- **Accessory widget** — a widget with very limited information (circular, corner, inline, rectangular) for the iPhone and iPad Lock Screen and Apple Watch. (`widgets`)
- **Account linking** — connecting an existing account to Sign in with Apple so people keep the information in it. (`sign-in-with-apple`)
- **Action button** — the hardware button on supported iPhone and Apple Watch models that people assign to a favorite function, chosen at setup and changed in Settings. (`action-button`)
- **Action extension** — lets people start content-specific tasks, like adding a bookmark, copying a link, editing an inline image, or translating selected text, without leaving the current context. (`activity-views`)
- **Action sheet** — a modal view that presents choices related to an action people initiate. (`action-sheets`)
- **Activation phrase** — what people say to Siri to run an App Shortcut; it must include the app name and can have variants. (`app-shortcuts`)
- **Activity rings** — the element that shows one person's daily progress toward Move, Exercise, and Stand goals, with colors and meanings matching the Activity app. (`activity-rings`)
- **Activity view (share sheet)** — presents tasks people can perform in the current context: sharing activities, actions like Copy and Print, and quick access to frequently used apps; it appears as a sheet or popover depending on device and orientation. (`activity-views`)
- **Adaptable sidebar style** — a tab view style that opens as a sidebar or a tab bar (the app chooses), with a button to switch between them, adapting to platform, rotation, and window width. (`sidebars`)
- **Advanced Options** — the label for advanced print settings hidden behind a disclosure control until needed. (`printing`)
- **Agency** — let people do things their own way: freedom to act, staying informed, easy recovery. (`design-principles`)
- **Alert** — the modal view every platform can present, delivering important information related to your app or game. (`modality`)
- **Alternate app icon** — an icon version people choose in the app's settings. (`app-icons`)
- **Alternative label** — text that isn't visible onscreen, which VoiceOver speaks to describe an element. (`voiceover`)
- **Alternative text label** — an invisible accessibility description that VoiceOver reads for a custom icon. (`icons`)
- **Altitude, pressure, azimuth** — the tilt, force, and orientation Apple Pencil can sense. (`apple-pencil-and-scribble`)
- **Always On** — the low-power, privacy-preserving state in which a device with an Always On display keeps giving glanceable information after people stop interacting, by dimming the display and minimizing onscreen motion. (`always-on`)
- **Ambient audio / audio source** — pervasive sound that anchors people in a virtual world, versus sound that seems to come from a specific object. (`playing-audio`)
- **Amount Pending** — the subtotal label for a cost not known at checkout, like a ride priced by distance or a tip added later. (`apple-pay`)
- **Animated symbols** — animations applied to SF Symbols or custom symbols (SF Symbols 5 or later). (`motion`)
- **Annotating** — assigning a specific color or hierarchical level (primary, secondary, tertiary) to each layer of a custom symbol. (`sf-symbols`)
- **Annotation** — a marker for a custom point of interest; by default a red tint with a white pin icon. (`maps`)
- **App banner** — the system banner at the top of the screen when people first launch an App Clip, linking to the full app's App Store page. (`app-clips`)
- **App Clip** — a lightweight version of an app or game, instantly available without the full download, offering an on-the-go task or a demo and staying on the device only for a limited time. (`app-clips`)
- **App Clip card** — the system-provided card that is people's first interaction with an App Clip; it launches the App Clip or opens the full app's App Store page. (`app-clips`)
- **App Clip Code** — Apple's generated, immediately recognizable code that people scan or tap to launch an App Clip; the best way to discover one. (`app-clips`)
- **App drawer** — the place in Messages where an installed iMessage app or sticker pack's icon appears. (`imessage-apps-and-stickers`)
- **App extension** — code people can install to extend the functionality of a specific area of the system. (`file-management`, `activity-views`, `virtual-keyboards`)
- **App menu** — the menu titled with the app's short name (shown in bold), holding items that apply to the whole app rather than a task, document, or window. (`the-menu-bar`)
- **App sandboxing** — (macOS) giving an app access to system resources and user data while protecting it from malware; required on the Mac App Store. (`privacy`)
- **App schema** — a preset template for functionality the system already understands (email, music, photos) that brings built-in natural-language handling. (`siri`)
- **App schemas** — schemas that apps in common domain areas adopt so Apple Intelligence can surface their actions and content contextually. (`app-shortcuts`)
- **App Shortcut** — one or more of an app's actions, packaged to expose a key function or content systemwide (Siri, Spotlight, the Shortcuts app, the Action button, Apple Pencil squeeze), available as soon as installation finishes. (`app-shortcuts`, `action-button`)
- **App Shortcuts** — the way to expose custom actions that fall outside the existing schema domains. (`siri`)
- **App tracking** — tracking supported by the device's advertising identifier; it requires the system alert before any tracking data is collected. (`privacy`)
- **Appearance variants** — the default, dark, clear, and tinted Home Screen icon looks people choose in iOS, iPadOS, and macOS. (`app-icons`)
- **Apple Business Register** — the registration that supplies your official organization name and logo to the ID verification UI. (`id-verifier`)
- **Apple menu** — the system menu always first on the leading side of the macOS menu bar; apps can't modify or remove it. (`the-menu-bar`)
- **Apple Pay button** — the API-generated button that starts payment, in a type whose verb fits the flow; in some contexts it shows an image of the default card. (`apple-pay`)
- **Apple Pay mark** — the graphic that shows Apple Pay is an available payment option; it isn't a button and doesn't facilitate payment. (`apple-pay`)
- **Approachable** — an experience that requires no particular skills or knowledge to start and gives a clear path toward deeper understanding. (`inclusion`)
- **App-specific activities** — actions an app adds to its share sheet (Photos adds Copy Photo, Add to Album, Adjust Location), listed by default before system-wide actions like Add to Files or AirPlay. (`activity-views`)
- **App-specific menus** — an app's custom menus, placed between View and Window, like Safari's History and Bookmarks. (`the-menu-bar`)
- **Arrangement view** — a container holding a primary and a secondary view that it organizes by display size, orientation, and reserved regions. (`designing-for-iphone-duo`)
- **Aspect mode** — fit-to-screen playback where the entire video is visible, letterboxed or pillarboxed as needed. (`playing-video`)
- **Aspect-fill mode** — full-screen playback where video scales to fill the display and some edge cropping may occur. (`playing-video`)
- **Assistive Access** — an iOS and iPadOS feature giving people with cognitive disabilities a streamlined version of an app, with a default layout and controls that reduce cognitive load. (`accessibility`)
- **Attribution** — the stated basis or rationale for a result, given without explaining exactly how the model works. (`machine-learning`)
- **Audio category** — the declared way an app uses sound, which sets whether it mixes with other audio, plays in the background, and obeys the Ring/Silent switch. (`playing-audio`)
- **Audio Graphs** — chart information given to VoiceOver, which constructs tones representing the data values and their trend, with optional high-level text summaries. (`charts`)
- **Auto appearance** — a setting that switches between light and dark as conditions change throughout the day. (`dark-mode`)
- **Automatic storage management** — overwrites the oldest or already viewed recordings so people don't run out of space. (`live-viewing-apps`)
- **Auto-renewable / non-renewing subscription** — access that renews automatically each period until people cancel vs. access for a limited time (an in-game battle pass) that people buy again to extend. (`apple-in-app-purchase`)
- **Auxiliary window** — a window dedicated to one task or area, with no navigation to other app areas, typically closed with a button once the task is done. (`windows`)
- **Axis** — a frame of reference for a set of marks, usually a horizontal and a vertical one at the plot area's edges, each representing a variable like time, amount, or category. (`charts`)
- **Background extension effect** — mirroring adjacent content to give the impression of stretching it under the sidebar. (`sidebars`, `layout`)
- **Background fill and center image** — the two image layers of a document icon, which the system layers, positions, and masks with optional text into the folded-corner shape. (`icons`)
- **Background selection** — in macOS, selected content in an inactive window, which looks different from a selection in the active window. (`drag-and-drop`)
- **Background style** — automatic, prominent, or minimal: whether the control's translucent rounded-rectangle background shows during interaction, always, or never. (`page-controls`)
- **Badge** — a small filled oval with a number on an app icon, counting unread notifications. (`notifications`, `drag-and-drop`, `tab-bars`)
- **Badge design** — the App Clip Code design that shows the App Clip logo below the code. (`app-clips`)
- **Bar compression** — which bar yields when space runs out: toolbar items go to overflow by default, or the tab bar minimizes in task-oriented views. (`designing-for-iphone-duo`)
- **Barrel roll** — rotating Apple Pencil Pro while marking to change the mark it makes. (`apple-pencil-and-scribble`)
- **Base and elevated colors** — the two iOS and iPadOS Dark Mode background sets: dimmer base colors recede, brighter elevated colors advance. (`dark-mode`)
- **Billing agreement field** — an optional plain-language summary of subscription terms on the payment sheet, not a substitute for formal terms. (`apple-pay`)
- **Bordered style** — (macOS) a table style with alternating row backgrounds that makes large tables easier to use. (`lists-and-tables`)
- **Bottom bar** — a rarely used part of a macOS window frame that appears below the body content, like Finder's status bar. (`windows`)
- **Box** — a visually distinct group of logically related information and components, set apart by a visible border or background color and optionally titled; iOS and iPadOS use the secondary and tertiary background colors by default, and macOS places the title above the box. (`boxes`)
- **Button appearance** — an iOS search tab shown as a separate button that focuses the field and raises the keyboard immediately. (`search-fields`)
- **Button role** — a system-defined semantic meaning (normal, primary, cancel, destructive) that can change the button's appearance. (`buttons`)
- **Calibration** — a process in which people provide information a feature needs to function, like scanning a face to set up Face ID. (`machine-learning`)
- **Camera Control** — the iPhone hardware control that opens your camera experience; a light press shows the overlay, a light double-press shows the available controls, and sliding adjusts a value. (`camera-control`)
- **Camera experience on a locked device** — from iOS 18, a control that launches straight into an app's camera capture while the device stays locked. (`controls`)
- **Centered ellipsis** — truncation that puts the ellipsis in the middle of the text, preserving its beginning and end. (`outline-views`)
- **Change message** — a per-field notification that interrupts people when a pass field changes. (`wallet`)
- **Checkbox** — a small square button: empty when off, a checkmark when on, a dash when mixed, usually with a trailing title. (`toggles`)
- **Circular progress indicator** — a determinate track that fills clockwise. (`progress-indicators`)
- **Clear variant** — the highly translucent Liquid Glass variant for components floating over media backgrounds. (`materials`)
- **Clipping** — in macOS, a temporary container for dragged content, like text dragged to the Finder; unrelated to the Clipboard. (`drag-and-drop`)
- **Cloud DVR** — digital video recording in the cloud. (`live-viewing-apps`)
- **Cluster** — a single pin that represents several nearby points of interest and expands as people zoom in. (`maps`)
- **Collaboration button** — the system button that appears once collaboration starts, showing that content is shared and who's sharing it, and opening the collaboration popover. (`collaboration-and-sharing`)
- **Collaboration-management view** — where people change settings and add or remove collaborators, opened by the "Manage Shared File" button. (`collaboration-and-sharing`)
- **Collection** — a component that manages an ordered set of content and presents it in a customizable, highly visual layout (a horizontal row or a grid by default); ideal for image-based content. (`collections`)
- **Color profile** — a description of a color space that an image embeds so a device reproduces its colors correctly. (`color`)
- **Color space (gamut)** — the set of colors a color model like RGB can represent; common ones are sRGB and Display P3. (`color`)
- **Color well** — a control that opens a color picker, system-provided or custom, when people tap or click it, to adjust the color of text, shapes, guides, and other onscreen elements. (`color-wells`)
- **Column view (browser)** — a macOS view for navigating a data hierarchy through a series of vertical columns, one per level; a triangle icon marks parent items, and selecting a parent shows its children in the next column. (`column-views`)
- **Combo box** — a macOS control combining a text field with a pull-down button, so people can type a custom value or choose from a list of predefined values. (`combo-boxes`)
- **Communication and noncommunication notifications** — notifications for direct communication like phone calls and messages (delivery depends on the sender) versus all other tasks (delivery depends on the interruption level). (`managing-notifications`)
- **Communication notification** — a notification about direct communication, like a call or message, that shows avatars and group names instead of the app icon. (`notifications`)
- **Compact environment** — a layout with little horizontal space, such as iPhone in portrait orientation, where multiple panes are hard to display without wrapping or truncating; the opposite of a regular environment. (`split-views`)
- **Compact (horizontal) style** — the edit menu as a short horizontal list, shown when people reveal it by touch; in iOS a chevron on the trailing edge expands it into a context menu. (`edit-menus`)
- **Compact presentation** — the Dynamic Island view when one Live Activity is active, split into leading and trailing elements around the camera. (`live-activities`)
- **Compact view** — the iMessage app view below the message transcript, roughly the height of the keyboard. (`imessage-apps-and-stickers`)
- **Complementary vs. critical** — machine learning is complementary when the app still works without the feature (QuickType suggestions) and critical when it can't (Face ID). (`machine-learning`)
- **Confirmation sheet** — the system sheet shown at purchase to help prevent accidental purchases. (`apple-in-app-purchase`)
- **Confirmation snippet** — lets people confirm or cancel an action, possibly with options that affect the result. (`snippets`)
- **Consumable / non-consumable** — content that depletes with use and can be bought again (lives, gems) vs. content that doesn't expire once bought (premium features). (`apple-in-app-purchase`)
- **Content effect** — a change in the appearance of the element or region beneath the iPadOS pointer while people hold the pointer over it; the pointer keeps its shape or transforms to integrate with the element. (`pointing-devices`)
- **Content footer** — a row of content thumbnails people browse during playback without leaving the live-viewing experience. (`live-viewing-apps`)
- **Content layer** — the layer of app content beneath Liquid Glass, where standard materials provide structure. (`materials`, `branding`)
- **Content tabs** — tabs below the transport controls, like Info, Episodes, or Chapters, offering supporting information and streamlined navigation. (`playing-video`)
- **Context menu** — a menu, hidden by default, of functionality directly related to an item, revealed by touch or pinch and hold, Control-click, or a secondary click on a Magic Trackpad; on a Mac it's sometimes called a contextual menu. (`context-menus`)
- **Context-specific tip** — a tip integrated into the experience that teaches the current task, shown near the area of the interface it refers to. (`onboarding`)
- **Contextual menu** — the name sometimes used on the Mac for a context menu. (`mac-catalyst`)
- **Continuous capacity indicator** — a horizontal translucent track that fills with a solid bar to the current value. (`gauges`)
- **Continuous event** — a haptic that feels like a sustained vibration, like the lasers effect in a message. (`playing-haptics`)
- **Control** — a button or toggle, made of a symbol, a title, and an optional value, that gives quick access to an app feature from Control Center, the Lock Screen, or the Action button. (`controls`)
- **Control button** — a control that performs an action, links to a specific area of the app, or launches a camera experience on a locked device. (`controls`)
- **Control toggle** — a control that switches between two states, such as on and off. (`controls`)
- **Controls gallery** — where people choose a control to add in Control Center or on the Lock Screen. (`controls`)
- **Copy** — the text you write for your app or game. (`inclusion`)
- **Craft** — care about every detail: the design reflects how much you care. (`design-principles`)
- **Critical notification** — urgent health and safety information that overrides the Ring/Silent switch; it requires an entitlement. (`managing-notifications`)
- **Custom gesture** — an app-defined gesture for specialized, frequent tasks that existing gestures don't cover. (`gestures`)
- **Custom keyboard** — an app extension people choose in Settings to replace the standard keyboard in any app (iOS, iPadOS, tvOS). (`virtual-keyboards`)
- **Custom settings area** — a settings area inside your app or game for general options that affect the overall experience, like interface style or game-saving behavior. (`settings`)
- **Custom shortcut** — a shortcut people build in the Shortcuts app by combining actions, even across apps; possible on Mac, where App Shortcuts aren't supported. (`app-shortcuts`)
- **Custom view** — the app-designed part of a snippet that shows its information and can hold buttons to modify content, get more information, or act. (`snippets`)
- **Dark Mode** — a systemwide appearance setting with a dark palette for low-light comfort, sometimes with greater perceptual contrast for foreground content. (`dark-mode`, `designing-for-ios`)
- **Data Transfer request** — delivers data like address or date of birth to your app to store or process; requires a legal verification need and an extra entitlement. (`id-verifier`)
- **Date picker modes** — date, time, date and time, and countdown timer, each presenting a different set of selectable values. (`pickers`)
- **Date picker styles** — in iOS and iPadOS: compact (a button that opens editable date and time content in a modal view), inline (wheels for time only, a calendar view for dates and times), wheels (also accepts keyboard entry), and automatic (system-chosen). (`pickers`)
- **Default button** — the alert button that responds to Return; it sits on the trailing side of a row or at the top of a stack. (`alerts`)
- **Default interaction method** — the input every device has: touchscreen, keyboard with trackpad or mouse, remote, or eyes and hands. (`game-controls`)
- **Deferring system gestures** — making the exit take two swipes instead of one to prevent accidental exits from a full-screen app or game. (`going-full-screen`)
- **Deferring the system overlay** — requiring a tap before the Home indicator appears when people look at their palm, for immersive apps in a Full Space. (`gestures`)
- **Delight** — make it human: deliver the emotions right for the experience in a satisfying, enriching way. (`design-principles`)
- **Demo App Clip** — an App Clip that lets people experience an app or game before committing to a purchase or subscription, e.g. a game's tutorial and first level. (`app-clips`)
- **Descriptive text** — titles, subtitles, annotations, and headline summaries that emphasize a chart's most important information. (`charting-data`)
- **Design variant** — an outline, fill, slash, or enclosed version of a symbol that communicates a state or action. (`sf-symbols`)
- **Desktop tinting** — in macOS with the graphite accent color, window backgrounds pick up color from the desktop picture. (`dark-mode`)
- **Destructive menu item** — an item, like Delete or Remove, identified as able to destroy data, which the system can display in red text. (`context-menus`)
- **Destructive style** — the button appearance that draws attention to a destructive action people didn't originally intend. (`alerts`)
- **Detached popover** — in macOS, a popover people drag away to turn it into a separate panel that remains visible while they interact with other content. (`popovers`)
- **Detail disclosure button** — an info button that appears in a list row; it reveals more information about the row's content but doesn't navigate a hierarchy. (`lists-and-tables`)
- **Detent** — a particular height at which a resizable sheet naturally rests; the system defines large and medium, and apps can add custom values. (`sheets`)
- **Determinate progress indicator** — for a task with a well-defined duration, such as a file conversion; it fills a linear or circular track as the task completes. (`progress-indicators`)
- **Device poses** — the ways people hold and set down iPhone Duo: partially folded like a book, placed down on a surface, or standing on its edges. (`designing-for-iphone-duo`)
- **Dialogue** — the app intent text Siri speaks; by default the system shows it above the custom view. (`snippets`)
- **Dim Flashing Lights** — a setting that lets the system calculate, mitigate, and inform people about flashing lights in media. (`accessibility`)
- **Dimming layer** — a dark layer behind clear Liquid Glass that restores contrast over bright content. (`materials`)
- **Directional field of view** — the sensor's field of view, within which an app gets a peer device's direction as well as its distance. (`nearby-interactions`)
- **Disclosure button** — shows and hides functionality associated with a specific control; points down when content is hidden and up when it's visible. (`disclosure-controls`)
- **Disclosure control** — a control that reveals and hides information and functionality related to specific controls or views. (`disclosure-controls`)
- **Disclosure indicator** — the accessory control at the trailing end of a row that lets people drill into the row's subviews. (`lists-and-tables`)
- **Disclosure triangle** — shows and hides content associated with a view or a list of items; points inward from the leading edge when content is hidden and down when it's visible, and the view expands or collapses to fit. (`disclosure-controls`)
- **Discrete capacity indicator** — a row of equal rectangular segments, one per unit of capacity, that fill completely, never partially. (`gauges`)
- **Display Only request** — shows a person's data (e.g. name or age with their portrait) in system UI on the requester's iPhone, without transmitting it to your app. (`id-verifier`)
- **Dock menu** — the menu people reveal on a Mac by secondary clicking an app's or game's icon in the Dock, holding system-provided and custom items. (`dock-menus`)
- **Document icon** — a macOS icon for a custom document type, traditionally a page with its top-right corner folded down. (`icons`)
- **Document launcher** — in iOS 18 and iPadOS 18, the system's full-screen way to browse, open, and create files: a title card (app name plus primary and secondary buttons), a background with images called accessories, and a file-browser sheet. (`file-management`)
- **Document menu** — a menu next to the title with commands for the whole document, like Duplicate, Rename, Move, and Export. (`toolbars`)
- **Document-based app** — an app, like Pages, Keynote, Photos, or Preview, that helps people create, edit, and save documents and files. (`file-management`)
- **Donating actions** — telling the system about actions people take (recent activity, items they showed interest in) so Siri can anticipate and surface them. (`siri`)
- **Double tap** — the Apple Pencil gesture that by default toggles between the current tool and the eraser, configurable systemwide. (`apple-pencil-and-scribble`)
- **Drag and drop** — an inter-app capability people expect to use between apps on iPad. (`designing-for-ipados`)
- **Drag image** — the representation of dragged content, ideally translucent, shown from the start of the drag until the drop. (`drag-and-drop`)
- **Dynamic Island** — the area around the iPhone TrueDepth camera that serves as a unified home for alerts and indicators of ongoing activity. (`live-activities`)
- **Dynamic menu item** — an item that changes behavior when chosen while pressing a modifier key, like Minimize becoming Minimize All with Option. (`the-menu-bar`)
- **Dynamic optical sizes** — the system fonts merge discrete optical sizes (like Text and Display) and weights into one continuous design adapted to each point size. (`typography`)
- **Dynamic quick actions** — quick actions the app updates when new information is available, like Messages listing recent conversations. (`home-screen-quick-actions`)
- **Dynamic system colors** — colors defined by semantic purpose (backgrounds at levels of hierarchy, labels, links, separators) that match standard components and adapt to light and dark. (`color`)
- **Dynamic Type** — a system-level feature in iOS, iPadOS, tvOS, visionOS, and watchOS (not macOS) that lets people adjust the size of visible text for readability and comfort. (`typography`, `accessibility`, `designing-for-ios`, `text-views`)
- **Edit menu** — commands for changing selected content (text, images, files, objects like contact cards, charts, or map locations) plus related commands like Copy, Select, Translate, and Look Up; the system can add an action for a detected data type, like Get directions for an address. (`edit-menus`)
- **Editable path control** — a path control onto which people can drag an item to select it and show its path; in the pop-up style its menu adds a Choose command. (`path-controls`)
- **Eligibility rules** — parameter-based or event-based rules that control when a tip appears. (`offering-help`)
- **Emphasis style** — the map's color treatment: default (fully saturated) or muted (desaturated). (`maps`)
- **Empty state** — a blank screen, like a completed to-do list or an empty bookmarks folder, that should guide people to a next step. (`writing`)
- **Entity** — app content exposed to the system; annotating views with entities tells Siri what's onscreen, and donating them to the Spotlight index makes them searchable. (`siri`)
- **EPG (electronic program guide)** — the guide containing information about scheduled programming. (`live-viewing-apps`)
- **Erase layer** — an offset path annotated to cut a gap into a whole shape, so a custom symbol keeps the layer information animations need. (`sf-symbols`)
- **Expanded presentation** — the larger view that appears when people touch and hold a compact or minimal Live Activity. (`live-activities`)
- **Expanded view** — the iMessage app view that occupies most of the window. (`imessage-apps-and-stickers`)
- **Expansion tooltip** — in macOS, a tooltip that shows the complete contents of a text field too small to display them, when the pointer rests on it. (`entering-data`, `text-fields`)
- **Explicit feedback** — information people provide in response to a specific request from the app. (`machine-learning`)
- **Express checkout** — a feature that immediately shows the payment sheet so people buy everything in the cart with one shipping method and destination. (`apple-pay`)
- **Familiarity** — build on what people know: established physical and digital patterns, applied consistently. (`design-principles`)
- **Family Sharing** — sharing purchased content, such as auto-renewable subscriptions and non-consumables, with family members across their Apple devices. (`apple-in-app-purchase`)
- **Featured actions** — quick links from a pass to related content, like venue directions or event guides. (`wallet`)
- **File provider app extension** — a custom interface for importing, exporting, opening, and moving an app's documents from other apps. (`file-management`)
- **Finder Sync extension** — in macOS, an extension that expresses sync status and control in the Finder through badges, contextual menu items, and toolbar buttons. (`file-management`)
- **Fixed / dynamic axis range** — axis bounds that never change versus bounds that vary with the current data. (`charts`)
- **Fixed / tracked sound** — sound perceived as pointed at the wearer regardless of where they look, versus sound perceived as coming from a particular object. (`playing-audio`)
- **Flexibility** — adapt to diverse contexts and needs: many devices, types of interaction, and perspectives. (`design-principles`)
- **Flocking** — visually grouping multiple drag items during a drag so people can confirm none is missing, then ungrouping them on drop. (`drag-and-drop`)
- **Floor picker** — a control that lets people jump between the levels of a venue. (`maps`)
- **Focus** — a period people reserve for an activity like sleeping, working, reading, or driving, during which notification alerts are filtered; it can delay an alert, but the notification is available as soon as it arrives. (`managing-notifications`)
- **Focus group** — an iPadOS app area like a sidebar, grid, or list; Tab moves between groups and arrow keys move within one. (`focus-and-selection`)
- **Focus system (focus model)** — the combination of focus effects and interactions a platform uses. (`focus-and-selection`)
- **Folding region** — when the device is partially open, the center of the inner display, excluded so the display divides into separate usable regions. (`designing-for-iphone-duo`)
- **Freemium app, metered paywall, free trial** — the example forms of limited free access that let people sample content before subscribing. (`apple-in-app-purchase`)
- **Full Keyboard Access** — the accessibility feature that lets people navigate and activate everything onscreen using only the keyboard. (`keyboards`, `accessibility`, `focus-and-selection`)
- **Full screen and windowed** — the two iPadOS window presentations people choose in Multitasking & Gestures settings: app windows fill the screen, or people freely resize, reposition, and layer them. (`windows`)
- **Full-screen modal experience** — a modal presentation that fills a window or the device display, for temporary experiences like viewing media or distinct multistep tasks like editing content. (`modality`)
- **Full-screen mode** — on iPhone, iPad, and Mac, expanding a window to fill the screen and hiding system controls; Apple TV and Apple Watch apps already fill the screen, and Apple Vision Pro uses larger windows or immersion instead. (`going-full-screen`, `designing-for-macos`)
- **Game Center** — Apple's social gaming network on all platforms: progress, achievements, leaderboards, challenges, multiplayer, and discovery across devices and friends. (`designing-for-games`)
- **Gauge** — a circular or linear path that maps a value within a range: the standard style marks the value with an indicator, the capacity style fills up to it. (`gauges`)
- **Globe key** — the standard keyboard key that switches keyboards, replacing the Emoji key when several keyboards are available. (`virtual-keyboards`)
- **Grabber** — a small horizontal indicator at the top edge of a resizable sheet that people drag to resize it or tap to cycle through detents. (`sheets`)
- **Grouped style** — (iOS, iPadOS) a list style that separates groups of data with headers, footers, and additional space. (`lists-and-tables`)

- **Shortcut gesture** — a custom gesture that accelerates a standard action, like an edge swipe for Back, offered alongside the standard control. (`gestures`)
- **Sidebar** — a navigation area on the leading side of a view for moving between app areas or top-level collections like folders and playlists. (`sidebars`)
- **Sign in with Apple** — a consistent sign-in experience people can trust, sparing them from remembering multiple accounts and authentication methods. (`managing-accounts`)
- **Simplicity** — be clear and direct: remove the unnecessary so every element earns its place. (`design-principles`)
- **Siri AI** — the version of Siri powered by Apple Intelligence on supported devices, able to run app actions from anywhere and act on onscreen content. (`siri`)
- **Situational disability** — a disability imposed by circumstances, like being unable to hear on a noisy train. (`inclusion`)
- **Size class** — compact or regular, per dimension, describing how much horizontal and vertical space an iOS or iPadOS interface has; set by device, window configuration, and multitasking state. (`layout`)
- **Slider** — a horizontal track with a thumb that people adjust between a minimum and maximum value; the track between the minimum and the thumb fills with color. (`sliders`)
- **Slider and picker** — the two Camera Control types: a range of values (like contrast) and discrete options (like a viewfinder grid on or off). (`camera-control`)
- **Snippet** — a compact view that shows a result or asks for confirmation after someone acts through Siri, Spotlight, the Shortcuts app, or an App Shortcut. (`snippets`)
- **Source / destination** — where people pick up dragged content and where they drop it: the same container, different containers, or different apps. (`drag-and-drop`)
- **Spatial Audio** — sound people perceive as coming from specific locations in space, not just from speakers, built from audio algorithms and knowledge of the physical surroundings. (`playing-audio`, `designing-for-games`)
- **Spatial photo** — a 3D (stereoscopic) photo carrying spatial metadata, taken with iPhone 15 Pro or later, Vision Pro, or a compatible camera. (`images`)
- **Spatial scene** — a 3D image generated from a 2D image, adding a parallax effect that responds to head movement. (`images`)
- **Splash screen** — a beautiful graphic that succinctly communicates branding and other information, shown at the start of onboarding or right after launch. (`launching`)
- **Split and overlay arrangements** — split divides the area (horizontally when wider than tall, vertically when taller than wide); overlay layers the primary view atop the secondary, moving them to each side when partially folded. (`designing-for-iphone-duo`)
- **Split view** — manages multiple adjacent panes of content; selecting an item in the primary pane shows its contents in the secondary pane, and a tertiary pane can show further content, often with a sidebar as the leading pane. (`split-views`)
- **Spotlight** — systemwide search in iOS, iPadOS, and macOS that finds content across all apps and on the web, including content apps index. (`searching`)
- **Spotlight File Importer plug-in** — a plug-in that describes the types of metadata a custom file format contains. (`searching`)
- **Spring loading** — on a Magic Trackpad, activating a button by dragging items over it and force clicking, without dropping the items. (`buttons`, `drag-and-drop`, `segmented-controls`)
- **Square button (gradient button)** — a macOS button holding a symbol, placed in or under a view to act on it, like adding or removing table rows. (`buttons`)
- **Squeeze** — the Apple Pencil Pro gesture for a discrete action, available while the pencil isn't touching the screen. (`apple-pencil-and-scribble`)
- **Standard gestures** — the basic gestures every platform supports (tap, swipe, drag, and more), whose functionality people expect everywhere. (`gestures`)
- **Standard keyboard shortcuts** — Apple-defined shortcuts that work consistently across the system and most apps. (`keyboards`)
- **Standard materials** — blur, vibrancy, and blending effects in different thicknesses that convey structure in the content layer. (`materials`)
- **Standard style** — a linear list of the root disk, parent folders, and selected item, each with an icon and a name. (`path-controls`)
- **Standard tab** — an iOS search tab styled like the other tabs that opens a search landing page with the field at the top. (`search-fields`)
- **StandBy** — the iPhone Lock Screen view showing two small widgets side by side, scaled up with backgrounds removed, red-tinted in low light. (`widgets`)
- **Static and dynamic interfaces** — long-look interfaces: static shows the message with packaged text and images, dynamic accesses the full content with more configuration options. (`notifications`)
- **Stationary frame of reference** — an area that doesn't move, containing visual movement so people can handle it comfortably. (`motion`)
- **Status bar** — the strip along the upper edge of the screen that shows the device's current state, like the time, cellular carrier, and battery level. (`status-bars`)
- **Status feedback** — passive information about the current state of something, shown near the items it describes so people can check it when they're interested. (`feedback`)
- **Stepper** — a two-segment control people use to increase or decrease an incremental value; it shows no value and sits next to a field that does. (`steppers`)
- **Sticker pack** — a set of images for decorating a conversation, available in Messages conversations and in effects in Messages and FaceTime. (`imessage-apps-and-stickers`)
- **Submenu** — a subordinate list of closely related items, revealed by an item that shows a symbol such as a chevron after its label; functionally identical to a menu. (`menus`, `context-menus`)
- **Summary rating** — the summary of individual ratings received since the last reset, which you can reset when you release a new version. (`ratings-and-reviews`)
- **Suppression checkbox** — a macOS alert option that lets people suppress later occurrences of a repeating alert. (`alerts`)
- **Switch** — the toggle style that in iOS and iPadOS belongs only in a list row, and in macOS carries more visual weight than a checkbox. (`toggles`)
- **Switch Control** — controlling a device through separate hardware, game controllers, or sounds such as a click or a pop. (`accessibility`)
- **Symbol scale** — a symbol's small, medium, or large size relative to the San Francisco cap height, which preserves weight matching with text. (`sf-symbols`)
- **Symbolic traits** — font adjustments that modify a text style, such as the bold trait or looser or tighter leading. (`typography`)
- **System family widget** — the main widget sizes, small to extra large (plus extra large portrait on Vision Pro), which can include interactive elements. (`widgets`)
- **System-provided rating prompt** — the in-app prompt in iOS, iPadOS, and macOS that asks for a rating and an optional written review, shown only when there's no previous feedback. (`ratings-and-reviews`)
- **System-provided Settings app** — where people adjust systemwide options and, on some platforms, an app's access to location, microphone, camera, and system features like notifications, Siri, or Search. (`settings`)
- **Tab bar** — a bar for navigating between an app's top-level sections while preserving each section's navigation state; in iOS it floats at the bottom on a Liquid Glass background, in iPadOS it sits near the top, in visionOS it's vertical on the window's leading side. (`tab-bars`)
- **Tab bar accessory** — a view attached to an iOS tab bar, like the MiniPlayer in Music; the tab bar can minimize as people scroll down, moving the accessory inline, until they tap a tab or scroll to the top. (`tab-bars`)
- **Tab view** — presents multiple mutually exclusive panes of content in the same area, which people switch between with a tabbed control. (`tab-views`)
- **Tabbed control** — the control on the top edge of a tab view's content area; it can be hidden when the app switches panes programmatically, leaving a borderless, bezeled, or line-bordered content area. (`tab-views`)
- **Task-specific options** — options that affect only one task, offered within that task so people don't leave the experience to customize it. (`settings`)
- **Template image** — an interface image (complication image, menu icon) whose transparency tells the system where to apply color. (`images`)
- **Temporary disability** — a short-term disability, like hearing loss from an infection. (`inclusion`)
- **Text style** — a system-defined combination of weight, point size, and leading for each text size (e.g. body, headline); together the styles form a hierarchy that scales with the system text size. (`typography`)
- **Text view** — a view that displays multiline, styled text, optionally editable; it can be any height, scrolls when content overflows, and by default is leading-aligned in the system label color. (`text-views`)
- **Textual and graphical date pickers** — the two macOS date picker styles: text for specific selections in limited space, or a calendar or clock face for browsing and ranges. (`pickers`)
- **Thin divider** — (macOS) the 1 pt divider style between panes, preferred over thicker styles. (`split-views`)
- **Thumb** — the control people move along a slider's track: a narrow lozenge in a macOS linear slider, a small circle in a circular one. (`sliders`)
- **Tick marks** — marks along a macOS slider that show the scale of measurement and help people pinpoint a specific value. (`sliders`)
- **Ticks and grid lines** — reference points along an axis for important values (like 0, 50%, 100%), and lines extending from ticks across the plot area to help estimate values far from an axis. (`charts`)
- **Tiered state** — a capacity indicator that shows a sequence of several fill colors in one indicator. (`gauges`)
- **Time Sensitive notification** — a notification with essential information people appreciate getting right away; it can break through Focus and scheduled delivery. (`managing-notifications`)
- **Tip** — a small, transient view that briefly describes how to use a feature, for teaching new or less obvious features or faster ways to do a task. (`offering-help`)
- **Title case / sentence case** — capitalization styles; title case is generally considered formal, sentence case more casual. (`writing`)
- **Title-style capitalization** — capitalizing every word except articles, coordinating conjunctions, and short prepositions, and always the last word. (`menus`)
- **Toggle** — a control for choosing between a pair of opposing states, like on and off, with a different appearance for each. (`toggles`)
- **Toggled menu item** — a single item that communicates an attribute's current state and lets people change it. (`menus`)
- **Token** — a piece of text (a recipient, or in some situations a search term) encapsulated so people can select and act on it as one item. (`token-fields`, `search-fields`)
- **Token field** — a macOS text field that converts text into tokens that are easy to select and manipulate, like Mail's address fields, where people drag recipient tokens to reorder them or move them to another field. (`token-fields`)
- **Tone** — how the voice varies with the situation people are in at that moment. (`writing`)
- **Tool picker** — the system palette of drawing tools and ink, which includes undo and redo only in regular environments. (`apple-pencil-and-scribble`)
- **Toolbar** — sets of controls along the top or bottom edge of a view holding the view's title, navigation controls and search, and actions (bar items); unlike a tab bar, it isn't specifically for moving between app areas. (`toolbars`)
- **Tooltip (help tag)** — a small, transient view describing how to use a component, shown on pointer hover on a Mac (including iPhone and iPad apps) or on gaze or hover in visionOS; "help tag" is its name in user documentation. (`offering-help`)
- **Touch controls** — virtual game controls drawn on top of game content in iOS and iPadOS. (`designing-for-games`)
- **Transient event** — a brief, compact haptic that feels like a tap or impulse, like tapping the Flashlight button on the Home Screen. (`playing-haptics`)
- **Transparency** — iCloud's fundamental principle: people don't need to know where content resides and can assume they're always accessing the latest version. (`icloud`)
- **TV app** — the app giving global access to favorite, recently played, and recommended video, which opens your app when people start your content. (`playing-video`)
- **TV Provider Authentication** — system-level sign-in to a TV provider account, so people don't authenticate app by app. (`managing-accounts`)
- **Undo and redo alert** — the iPhone alert shown when people shake the device, which describes the result and lets people perform or cancel the undo; its title begins with an automatic "Undo " or "Redo " prefix. (`undo-and-redo`)
- **Variable color** — coloring a symbol's layers as a value crosses thresholds from 0 to 100%, to show change such as capacity or strength. (`sf-symbols`)
- **Verify with Wallet** — the system button and sheet that let people share identity information from an ID card stored in Wallet. (`wallet`)
- **Vertical controls** — the Dynamic Island, status bar, toolbar, and tab bar placed along the side of the display instead of top and bottom. (`designing-for-iphone-duo`)
- **Vertical style** — the edit menu opened directly as a context menu, shown when people reveal it with a keyboard or pointing device. (`edit-menus`)
- **Vibrancy** — pulling light and color forward from the background so text, symbols, and fills on a material stay legible. (`materials`)
- **Virtual controls** — onscreen game controls drawn over game content in iOS and iPadOS games. (`game-controls`)
- **Virtual keyboard** — the system keyboard on devices without a physical one, with keys optimized for the task; it doesn't support keyboard shortcuts. (`virtual-keyboards`)
- **Visible vs. invisible feature** — a visible feature offers choices people see and judge (Image Playground); an invisible one improves results unnoticed (News suggesting topics), so it struggles to show reliability or get feedback. (`machine-learning`)
- **VOD (video-on-demand)** — non-live content, which live content must be distinguishable from at a glance. (`live-viewing-apps`)
- **Voice** — the app's consistent way of speaking, chosen for its audience and values. (`writing`)
- **VoiceOver** — a screen reader that lets people experience an app's interface without needing to see the screen. (`voiceover`)
- **VoiceOver rotor** — an interface element for navigating a document or webpage by headings, links, and other content types; it can also bring up the braille keyboard. (`voiceover`)
- **Volume view** — the system control combining a volume-level slider with a control for rerouting audio output. (`playing-audio`, `sliders`)
- **Web view** — a view that loads and displays rich web content, such as embedded HTML and websites, directly within an app; Mail uses one to show HTML content in messages. (`web-views`)
- **Western and Eastern Arabic numerals** — the two numeral systems RTL locales use; Hebrew uses Western, Arabic uses either, varying by region. (`right-to-left`)
- **White with outline** — the button appearance for white or light backgrounds that don't contrast with a white fill (iOS, macOS, web). (`sign-in-with-apple`)
- **Wide color** — the P3 color space on compatible displays, richer and more saturated than sRGB. (`color`)
- **Windowed apps** — in iPadOS, resizable app windows people arrange as on a Mac, with system controls for tiling, full screen, minimizing, and closing; the frontmost window has colored controls and a drop shadow. (`multitasking`)
