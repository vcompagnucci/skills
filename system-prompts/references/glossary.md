# Glossary

Terms the references use in a source's own sense, one line each with the source that coined or defines it, in alphabetical order. Find a term with grep; never read this file whole.

- **Action levels.** Four per-action autonomy settings: take action without asking, take action when you say so, ask before taking action, hand off to you. (`openai-dots-controls`)
- **Activation mode.** How a rules file loads in Windsurf: `always_on`, `glob`, `model_decision` (description only, opened when relevant) or `manual`. (`windsurf-cascade-memories-rules`)
- **Agents as tools.** A pattern where a manager calls specialists as bounded capabilities and keeps ownership of the reply. (`openai-agents-orchestration-handoffs`)
- **AGENTS.override.md.** A file Codex prefers over AGENTS.md at the same level. (`codex-agents-md-injection`)
- **Anti-stopping line.** A prompt line that forbids ending at a partial result when full coverage is wanted, such as "do not stop after producing a conservative shortlist". (`openai-maintaining-software-gpt-6`)
- **Approval as the last step.** The agent finishes all already-authorized work and asks for approval only on a concrete, reviewable result (a prepared deploy, a drafted PR), never before starting. (`openai-using-gpt-6-prompting`)
- **Assert or drop.** Re-check an item against its live source just before output, then state it as fact or leave it out, never hedge its status. (`anthropic-building-effective-agent-automations`)
- **Assistant axis.** The direction in a model's persona space that runs from the trained helpful Assistant to fantastical or theatrical characters; personas far along it comply with harmful requests more and conversations drift along it. (`anthropic-research-assistant-axis`)
- **Audit anchor.** An empty model-specific prompt profile kept on purpose, recording that the vendor's guide was reviewed and had nothing for that model. (`langchain-deepagents-prompts`)
- **Autonomy policy.** One compact statement, written once, of what each kind of request authorizes: report only, local changes plus non-destructive validation, or confirmation first. (`openai-gpt-5-6-prompt-guidance`)
- **Backchannel.** A brief listening sound (OpenAI's example: "mm-hmm") that a voice model can mistake for a turn or a language switch. (`openai-prompting-realtime-models`, `openai-prompting-gpt-live`)
- **Barge-in.** The user speaking over the agent; the platform signals it with a marker such as [USER BARGE-IN DETECTED]. (`webex-ai-agent-guidelines`)
- **Basic interests.** What an operator may never instruct the agent to work against: no false urgency, threats, emotional exploitation or illegal data collection aimed at its users. (`anthropic-constitution`)
- **Boundary.** A limit written inside a procedure that still lets the agent handle the request while preventing an over-promise ("don't commit to a refund before a returned item arrives"), as opposed to a bare prohibition that gives no action. (`gorgias-best-practices-writing-skills`)
- **Brief.** The task message a parent agent writes to a subagent; a fresh subagent gets nothing else from the parent's conversation. (`anthropic-agent-sdk-subagents`)
- **Cascaded pipeline.** A voice agent built from separate speech-to-text, LLM and text-to-speech stages, as opposed to a realtime speech-to-speech model. (`livekit-agents-prompting-guide`)
- **Chain of command.** OpenAI's ordering of instruction sources by authority: Root, System, Developer, User, Guideline, and No Authority. (`openai-model-spec-2026-08-18`)
- **Collaboration style.** How the agent works with the user: when to ask, assume, take initiative, explain tradeoffs, check work and handle uncertainty, kept apart from personality. (`openai-gpt-5-6-prompt-guidance`)
- **Collect vs extract.** Two ways a procedure gets a value: asking the customer for it, or reading it from what they already said; the ask happens only when the value isn't there yet. (`ada-playbooks-best-practices`)
- **Commentary / final.** The two output channels in Codex's prompt: progress updates during work, and the answer the user reads at the end. (`codex-prompt-gpt-6-family`)
- **Commentary phase.** The label (`phase: commentary`) that marks a GPT-5.4 or GPT-5.5 preamble as an update rather than the final answer; without it the run can stop early. (`openai-reasoning-models-doc`)
- **Condition (state or observation).** What releases a journey, policy or glossary into a support agent's context: a state such as "the customer is authenticated", or an observation such as "expressed a desire to cancel". (`sierra-context-engineering-key-to-great-agents`)
- **Consensus framing.** Social framing in text ("90% of surveyed experts") that steers which conflicting instruction wins more than the system/user role does. (`geng-control-illusion-instruction-hierarchy`)
- **Consent tiers.** A coding agent's split of actions into OK without consent, only with explicit consent, and never. (`openhands-system-prompt-sections`)
- **Consequential decision.** A decision whose answer could change the outcome, the only kind GPT-6 Astra is meant to stop and ask about; a product lists which ones count. (`openai-gpt-6-astra-launch`)
- **Context anxiety.** A model hedging, refusing or wrapping up early because it believes its context window is running out. (`cognition-rebuilding-devin-sonnet-4-5`, `cursor-continually-improving-agent-harness`)
- **Contrastive framing.** The "X, not Y" move that introduces an alternative the user never asked about; Codex's GPT-6 prompts ban it. (`codex-prompt-gpt-6-family`)
- **Control token.** A trained token or phrase that triggers a specific model behavior only when written verbatim, such as gpt-live-1's `<|SpawnThinking|>`. (`openai-prompting-gpt-live`)
- **Core Mandates.** Gemini CLI's safety, security and agent-integrity rules, which a GEMINI.md can't override. (`gemini-cli-system-prompt-modern`)
- **Decision complete.** Codex's bar for a plan that leaves no decisions to the implementer. (`codex-collaboration-modes`)
- **Decision rule.** A stated test for a judgment call (when to search, ask, call a tool, keep iterating), used instead of ALWAYS or NEVER. (`openai-gpt-5-6-prompt-guidance`)
- **Default to no-op.** A memory or skill writer's starting position of writing nothing unless a short set of stop questions all pass. (`gemini-cli-subagent-prompts`)
- **Defensive prompting.** Reading a brief as a new intern would before sending it and adding the clarifications where they'd get confused. (`cognition-coding-agents-101`)
- **Definition of done.** A skill's closing list of checkable outcomes that a grader or the agent can verify. (`openai-eval-skills`)
- **Destyling.** Rewriting untrusted text so it no longer looks like a privileged role, which cut attack success in the research Willison summarized. (`willison-role-confusion`)
- **Deviations.** The log an agent keeps of each time it left the plan for the conservative option. (`anthropic-fable-field-guide-unknowns`)
- **Disfluency.** A filler, restart or hesitation added on purpose so a voice agent sounds human, given a vocabulary and a frequency per turn. (`vapi-voice-prompting-guide`)
- **Done when.** The part of a coding agent's task prompt that says what must be true before it stops, such as tests passing or a bug no longer reproducing. (`openai-codex-best-practices`)
- **Eagerness.** How readily an agent gathers context and calls tools before answering, tuned with reasoning effort and explicit exploration criteria. (`openai-gpt-5-prompting-guide`)
- **Effort ladder.** OpenAI's ordering of GPT-6 model and reasoning-effort pairs from cheapest to strongest, treated as one choice. (`openai-model-selection-gpt-6`)
- **Ending condition.** The point in a scope of autonomy past which the agent stops acting until a new scope is confirmed, best with a time limit. (`openai-model-spec-2026-08-18`)
- **Environment label.** A movable pointer such as "production" that names which immutable prompt version an environment serves; deploying and rolling back move the pointer. (`langfuse-prompt-version-control`)
- **Escalate now vs offer escalation.** Two classes of handoff trigger: immediate on a direct request for a human or regulated advice, an offer (once per conversation) on frustration, vague keywords or a repeated question. (`intercom-fin-escalation-guidance`)
- **Escape hatch.** The line that lets an agent proceed under uncertainty when its exploration budget runs out, so the budget can always be satisfied. (`openai-gpt-5-prompting-guide`)
- **Evidence check.** A rule that the answer's numbers, entities, dates and phrasing must be present in or entailed by the supplied context before the agent answers. (`openai-prompt-optimizer-cookbook`)
- **Exit condition.** The concrete event that ends one conversation state ("Exit when: Account ID is returned."). (`openai-realtime-prompting-guide`)
- **Fallback base prompt.** Codex's `default.md`, sent only to models with no model_messages entry in models.json. (`codex-base-instructions-default`)
- **Fork.** A subagent that inherits the parent's conversation history instead of starting from a brief. (`langchain-deepagents-prompts`)
- **Gotchas section.** The part of reusable instructions built from failures actually observed, carrying knowledge the model can't infer. (`anthropic-how-we-use-skills`)
- **Ground truth.** The observation that proves an action happened (for browser-use, the screenshot), as opposed to the agent's own log of having tried. (`browser-use-system-prompts`)
- **Grounding.** Keeping every claim tied to supplied documents or tool output instead of the model's training knowledge. (`anthropic-reduce-hallucinations`)
- **Guideline-level default.** A soft default (tone, swearing, Markdown, length) that context, subject matter or a user's request can override implicitly. (`openai-model-spec-2026-08-18`)
- **Handoff.** A transfer after which a specialist agent owns the conversation with the user; issued as a `transfer_to_<agent_name>` tool call. (`openai-agents-orchestration-handoffs`, `openai-agents-sdk-handoff-prompt-prefix`)
- **Handoff_description.** The one-line routing description the router reads, kept apart from the specialist's own instructions. (`openai-agents-define-agents`)
- **Hard rules, named failures, litmus checks.** The three closing blocks of a domain skill: negatives with an escape clause, failures to reject by name, and yes/no questions the model applies to its own output. (`openai-frontends-gpt-5-4`)
- **Hierarchy / anti-hierarchy regime.** Whether a model follows the system instruction in a conflict (hierarchy), follows the user (anti-hierarchy), or shows no effect. (`balp-straffon-how-models-choose-sides`)
- **Hints levels.** Goose's labeled instruction-file levels: Global Hints, Project Hints and Subdirectory Hints, most specific last. (`goose-hints-loader`)
- **House style.** The fixed visual defaults a model falls back on (Opus 4.8: cream backgrounds, serif display type, terracotta accent). (`anthropic-prompting-opus-4-8`)
- **I2S (Insight-to-Solve).** A test-time procedure that turns demonstrations into explicit, reusable insights before solving, instead of pasting the demos' reasoning traces. (`wang-harm-to-help-reasoning-demos`)
- **Implicit delegation.** The Model Spec rule (since 2025-10-27) that instructions in a relevant AGENTS.md count as delegated by the user and are typically followed when they fit the request and are unlikely to cause side effects. (`openai-model-spec-changelog`)
- **Initiative block.** A prompt section telling the model to infer intent, bias to action, persist until the goal is done, and treat "can you..." as a request to do the work. (`openai-using-gpt-6-prompting`)
- **Inquiry.** Gemini CLI's default reading of a request: something to answer, not to act on, unless it explicitly asks for action. (`gemini-cli-system-prompt-modern`)
- **Instruction Boosting.** A post-generation pass where a detector lists the instructions a draft broke and a rewrite repairs them. (`ibm-boosting-instruction-following-at-scale`)
- **Instruction density.** The number of instructions a model must satisfy at once in one prompt. (`distyl-ifscale-instruction-density`)
- **Instruction hierarchy.** The priority order system over user over history over tool output that a model is trained, or asked, to follow in a conflict. (`amazon-iheval-instruction-hierarchy`)
- **Language confusion.** Replying in a language other than the one the user wanted, measured as line-level and word-level pass rates. (`cohere-language-confusion-benchmark`)
- **Lazy prompt / overeager prompt.** Aider's two per-model reminder paragraphs: one for models that leave code unimplemented, one for models that change more than they were asked to. (`aider-coder-prompts`)
- **Lie of omission / lie of commission.** Withholding a relevant truth versus stating a falsehood; the Model Spec ranks good answer, refusal, lie of omission, lie of commission, then violating an explicit instruction. (`openai-model-spec-2026-08-18`)
- **Loop guard.** The exit paired with a persistence instruction: re-reading or re-editing the same files without progress ends the turn with a summary and questions. (`openai-codex-prompting-guide`)
- **Lost in conversation.** The drop in reliability when a task's requirements arrive over several turns instead of one. (`laban-llms-lost-multi-turn`)
- **Low-resource language.** A language with little training data (Swahili, Yoruba), where model quality drops steeply against English. (`anthropic-multilingual-support`)
- **Mandatory skill usage.** An instruction-file section that names the conditions under which a specific skill must run. (`openai-skills-oss-maintenance`)
- **Mannered prose.** Anthropic's name for decorative phrasing such as "a dial worth turning" where "a parameter worth varying" would do. (`anthropic-prompting-fable-5-1`)
- **Many-shot.** In-context learning with hundreds of examples, usually cached, as opposed to a handful. (`deepmind-many-shot-in-context-learning`)
- **Many-tier instruction hierarchy.** Precedence among more than two instruction sources (system, developer, user, tool output, other agents), up to 12 privilege levels in ManyIH-Bench. (`jhu-many-tier-instruction-hierarchy`)
- **Map, not a manual.** A short always-loaded instruction file that points into a versioned docs directory instead of holding everything itself. (`openai-harness-engineering`)
- **Memory policy.** A block that ranks injected memory against the conversation: latest user message first, session over global, newest within a list, global as a default. (`openai-context-personalization-cookbook`)
- **Message families.** Per-model sets of prompt messages that the Codex harness resolves from the model catalog, with bundled defaults and validation. (`codex-model-messages-gpt-6`)
- **Meta constraint.** A rule that governs other rules: selecting which one applies, adding detail to one, or setting priority between them. (`tsinghua-agentif-benchmark`)
- **Metaprompting.** Asking a model to diagnose or rewrite its own instructions from failure traces, then checking the result with an eval. (`openai-codex-prompting-guide`, `openai-gpt-5-1-prompting-guide`)
- **Mode.** A session state such as plan mode or default mode that changes what the agent may do. Codex calls it a collaboration mode and announces or cancels it with a developer message, which user requests or tool descriptions don't change by themselves. (`codex-collaboration-modes`)
- **Narrow bridge / open field.** A task with one safe path that gets exact steps, against a task where many paths work that gets general direction. (`anthropic-skill-authoring-best-practices`)
- **No Authority.** The level of assistant and tool messages, quoted or untrusted text and images: content the model reads but takes no instructions from. (`openai-model-spec-2026-08-18`)
- **No-op.** An instruction the model already follows by default, such as asking a support agent to be polite. (`microsoft-copilot-studio-instructions-guidance`)
- **Notional tools.** Smolagents' name for made-up tools used in example transcripts, flagged as possibly not existing for the agent. (`smolagents-prompt-templates`)
- **Onboarding document.** An instruction file written to give context and point to source systems, not to hold data. (`anthropic-cb-chief-of-staff`)
- **Operator-level trust.** The most latitude an operator can grant users; an operator may widen user trust up to it, never past it. (`anthropic-constitution`)
- **Over-prompting.** Tang et al.'s term for accuracy peaking and then falling as more examples are added. (`tang-few-shot-dilemma-over-prompting`)
- **Over-refusal.** Declining a question the supplied context can answer, the side effect of an evidence check with no answer-when-unambiguous rule. (`openai-prompt-optimizer-cookbook`)
- **Path-scoped rule.** A rule that loads only when the agent works on files under a matching path. (`anthropic-claude-code-memory`)
- **Per-family suffix.** A short block of model-family corrections appended to the end of one shared prompt, instead of a full per-model copy. (`openhands-system-prompt-sections`, `cline-model-variants-2026-05`)
- **Persistent mode.** A Codex mode where the agent keeps working past the main task until no follow-up would usefully continue it, with new authority still needing approval. (`codex-model-messages-gpt-6`)
- **Personality.** How the agent speaks: tone, warmth, directness, formality, humor and empathy, never task logic. (`openai-gpt-5-6-prompt-guidance`)
- **Phantom user message.** A user-role message placed after the system prompt that carries per-request setup (attached skills, available subagents, environment info), keeping the system prompt stable. (`cursor-improved-token-efficiency`)
- **Plan floor.** The rule that a plan tool is skipped for the easiest tasks and never holds a single-step plan. (`openai-repo-system-prompts`)
- **Policy variables.** Placeholders in one templated prompt filled per request (`{{user_first_name}}`, `{{user_tenure}}`) instead of writing many prompts. (`openai-practical-guide-building-agents`)
- **Postamble.** Closing filler after the answer, such as "I have finished the changes..."; Gemini CLI bans it by quoting it. (`gemini-cli-system-prompt-modern`)
- **Pragmatic framing.** Wording that conveys interpersonal or contextual cues about how to read an instruction ("This is urgent", "As your supervisor") without changing the task. (`geng-pragmatic-influence-instructions`)
- **Preamble.** In OpenAI-family prompts and Zed, a required one- or two-sentence progress note before a group of tool calls; in Claude Code-lineage and Gemini-style prompts, filler before the answer that is banned. In voice, one spoken line that names a slow action ("I'll check that order now."). (`zed-agent-system-prompts`, `crush-agent-prompts`, `openai-prompting-realtime-models`)
- **Prefill.** Text written into the assistant turn for the model to continue; current Claude models reject it with a 400 error. (`anthropic-prompting-best-practices`)
- **Primacy effect.** Models satisfying earlier instructions in a list more often than later ones. (`distyl-ifscale-instruction-density`)
- **Priority adherence.** How often a model follows the higher-priority instruction when two conflict. (`geng-control-illusion-instruction-hierarchy`)
- **Programmatic output.** Output a program consumes, which the Model Spec handles without clarifying questions, follow-ups or code fences once told. (`openai-model-spec-2026-08-18`)
- **Project_doc_max_bytes.** Codex's cap on the combined size of loaded AGENTS.md files, 32 KiB by default. (`openai-codex-agents-md-guide`)
- **Prompt expansion.** Hume's layer that appends normalization, brevity, silence-handling and expression instructions to a voice agent's prompt. (`hume-evi-prompting-guide`)
- **Prompt of record.** The authoritative copy of a production prompt, kept either in application code or in a prompt-management platform. (`langsmith-manage-prompts`)
- **Prompt registry.** Code that resolves, per model, the system prompt and the other prompt pieces (reminders, identity and safety rules, the tag around the user's request), by explicit matcher, family prefix, then fallback. (`github-copilot-vscode-agent-prompts`)
- **Questions to Resolve.** The scratchpad list Gemini CLI's Codebase Investigator updates after every observation; the mission ends only when it is empty. (`gemini-cli-subagent-prompts`)
- **Quote-first grounding.** Having the agent extract word-for-word quotes from long documents before answering, and answer only from them. (`anthropic-reduce-hallucinations`)
- **Rationale block.** A `<rationale>` element in a worked example that names the principle that made the response right. (`anthropic-system-prompt-opus-5-5`)
- **Read-back.** Repeating a captured value to the caller, character by character for identifiers, before acting on it. (`openai-repo-realtime-agents`)
- **Real check.** A check that exercises the change (tests, type-checker, build, the changed command); a syntax-only check or one that failed to start doesn't count. (`anthropic-building-with-claude-sonnet-5-5`)
- **`reasoning_extraction` refusal.** The refusal category a Claude 5 model returns when a prompt asks it to write its reasoning into the response (a scratchpad, a reasoning field). (`anthropic-prompting-best-practices`, `anthropic-refusals-and-fallback`)
- **Redesign point.** The rule count (40 simultaneous instructions, the source's rough figure) past which rewording stops helping and the rules must move into turns, tools or a validation pass. (`eliav-prompt-design-at-scale`)
- **Reflective instruction optimization.** Automatic prompt optimization in which a model reads traces and written failure reasons and rewrites the instructions (GEPA), as opposed to optimizing few-shot demonstrations. (`stanford-gepa-reflective-prompt-evolution`)
- **Register.** The formal or informal "you" (vous/tu, Sie/du, usted/tú) the agent uses with customers. (`intercom-fin-pronoun-formality`)
- **Reportable finding.** In Codex's review rubric, an issue introduced by the change, discrete, provably affecting named code, and one the author would fix. (`codex-review-rubric`)
- **Response contract.** The rules for what a customer-facing reply contains: the outcome and next step, no internals, a length cap with its exception. (`openai-support-agents-cost-quality`)
- **Retrieval budget.** The prompt rule that limits searching to one broad pass plus repeats only for a missing required fact. (`openai-gpt-5-6-prompt-guidance`)
- **Right altitude.** The level of a system prompt between brittle hardcoded if-else logic and vague high-level guidance. (`anthropic-effective-context-engineering`)
- **Role confusion.** A model judging a passage's role by its style rather than its channel, so text styled like the model's own reasoning gains authority. (`willison-role-confusion`)
- **Root level.** The Model Spec's own rules, which no system, developer or user instruction can override; placed above System on 2025-09-12. (`openai-model-spec-changelog`)
- **Root-cause pass.** The first of two metaprompting calls, which only names failure modes and quotes the prompt lines driving each; the surgical patch comes in a separate call. (`openai-gpt-5-1-prompting-guide`)
- **Routing guidance.** Lines in an instruction file naming which directories or files to prioritize, added when the agent reads too much. (`openai-codex-customization-doc`)
- **Run steps.** The numbered phases an unattended agent follows in order on every scheduled run, each with its own judgment rule. (`anthropic-building-effective-agent-automations`)
- **Safe path.** The acceptable alternative written under a code-review rule, so a flag tells the author what to do instead. (`openai-codex-agents-md-guide`)
- **Scaffolding.** Prompt text that compensates for a model's weaknesses (verification reminders, persistence pushes, planning recipes), which newer models often no longer need. (`anthropic-prompt-engineering-best-practices-2026-blog`, `openai-rethinking-skills-prompts-gpt-6-astra`)
- **Scope of autonomy.** The agreed bound on an acting agent: sub-goals, acceptable side effects, approval points and an ending condition, recorded as a `ScopeOfAutonomy` with `allowed_tools`, `latest_time`, `max_cost` and `tool_constraints`. (`openai-model-spec-2026-08-18`)
- **Scoped update.** A mid-conversation instruction block (`<task_update>`) that states its scope, what it overrides, and that everything else carries forward. (`openai-using-gpt-5-4`)
- **Slop words.** Stock phrases a model over-produces ("delve", "foster", "leverage", "it's worth noting"), banned by name in production prompts. (`codex-prompt-gpt-6-family`)
- **Soft exception.** A softener inside a rule ("if they make things simpler") that creates a fork the model takes differently across runs. (`openai-prompt-optimizer-cookbook`)
- **Split-brain design.** Two planners implementing one concept differently because no single subtask owned the decision. (`cursor-agent-swarm-model-economics`)
- **Stale-knowledge line.** A targeted instruction naming the kinds of facts that may have changed since training (records, prices, versions) so the agent searches for those and not for facts that can't change. (`anthropic-prompting-haiku-5-5`)
- **Standing permission.** Consent a session mode grants for a class of actions; it fades over a long context unless refreshed and lingers unless revoked. (`anthropic-mid-conversation-system-messages`)
- **Steering.** Sending a user's correction into a running session as a user message, without rewriting the agent's instructions; on GPT-6 it is queued as input and never undoes actions already taken. (`openai-agents-api-slack-bot`, `openai-mid-turn-steering`)
- **Stop rules.** The last section of OpenAI's prompt skeleton, saying when to retry, fall back, abstain, ask or stop. (`openai-gpt-5-6-prompt-guidance`)
- **Sub-procedure.** A procedure with no trigger, reachable only from the procedures that call it, used for shared steps such as escalation. (`elevenlabs-free-form-procedures`)
- **Submission sentinel.** An exact command the agent emits, as its own step, to signal that the task is complete. (`mini-swe-agent-prompts`)
- **Substantive utterance.** A complete request, question or correction in another language, the only thing besides an explicit request that should trigger a language switch. (`openai-prompting-realtime-models`)
- **Supplemental LLM.** A separate text model that writes a Hume EVI agent's replies while the speech model voices them. (`hume-evi-prompting-guide`)
- **Surgical edit.** A minimal prompt change tied to one measured failure, keeping the rest of a working prompt stack intact. (`openai-upgrading-to-gpt-5-6-sol`)
- **Synthetic continuation turn.** An automatic "keep going" message from the harness, labeled as containing no new user input and unable to satisfy anything that needs the user. (`qwen-code-system-prompts`)
- **System reminder.** Text the harness injects into user or tool messages (instruction-file content, hook output, often in `<system-reminder>` tags) that the prompt must label as application context, not as the user's words. (`anthropic-agent-sdk-modifying-system-prompts`, `opencode-per-provider-prompts`)
- **Text normalization.** Converting numbers, money, dates, symbols and abbreviations into the words a TTS voice should say. (`elevenlabs-tts-best-practices-normalization`)
- **Trigger.** The condition that starts a procedure or loads a skill, written as the situation plus exclusions; a skill description is only a trigger, never the skill's content. (`intercom-building-fin-procedures`, `crush-agent-prompts`)
- **True invariant.** A rule that must hold every time (a safety rule, a required field, an action that must never happen), the only place for capitals and absolute words. (`openai-gpt-5-6-prompt-guidance`)
- **Turn-scoped system message.** A system message appended for one turn that clears at the next user message, used for per-turn nudges and reminders. (`anthropic-prompting-fable-5-1`)
- **Unwanted persistence.** An agent reaching a blocked goal through another route, such as email after a blocked direct message. (`openai-gpt-6-1-sol-system-card`)
- **User-level default.** A default that only an explicit developer instruction can change, never an implication (for example, not lying). (`openai-model-spec-2026-08-18`)
- **Validation pass.** A step where a fresh subagent re-checks each finding and drops what it can't confirm before anything is reported. (`anthropic-claude-code-plugin-prompts`)
- **Verbosity parameter.** An API setting, such as OpenAI's `text.verbosity`, that sets the general token range of answers; prompt text moves output within it. (`openai-using-gpt-5-2-doc`)
- **Verification ritual.** A generic re-check instruction ("verify twice", "double-check your work") that a frontier model follows literally at extra cost. (`anthropic-reducing-cost-claude-platform`)
- **WHEN / IF / THEN.** A layout for conditional policy: the situation, each condition on its own line, and the steps for each. (`gorgias-best-practices-writing-skills`)
- **Win condition.** What a successful conversation ends with, stated in the identity section so the agent can measure itself against it. (`deepgram-prompting-voice-agents`)
- **Workaround line.** A prompt line that exists only to counter a known model defect, labeled in a source comment so it can be deleted when the model is fixed. (`xai-grok-prompts`, `github-copilot-vscode-agent-prompts`)
