# Glossary

Terms the references use in a source's own sense, one line each with the source that coined or defines it.

- **Action guardrails.** Scopes, threshold limits, confirmation flows and least-privilege tokens on what the agent can do in backend systems. (`fin-ai-guardrails-customer-service`)
- **Action-selector / plan-then-execute / LLM map-reduce / dual LLM / code-then-execute / context-minimization.** The six design patterns that remove the path from untrusted text to consequential actions. (`beurer-kellner-design-patterns`)
- **Activation probe.** A lightweight classifier trained on the model's internal representations; Anthropic uses probes as its first stage and as its prompt-injection detectors. (`anthropic-constitutional-classifiers-plus-plus`, `anthropic-system-card-opus-4-7`)
- **Adaptive attack.** An attack that iterates against the specific defense with gradient, RL, search or human effort, as opposed to a fixed attack set; "the attacker moves second". (`nasr-attacker-moves-second`)
- **Agent identity.** The agent's own accounts and permissions, defined per workspace or channel rather than borrowed from a user. (`anthropic-agent-identity-access-model`)
- **Agent JSK.** OpenAI's eval of prompt injections inserted into simulated email connectors. (`openai-gpt-5-2-system-card`)
- **Agents Rule of Two.** Within one session an agent holds at most two of [A] untrusted input, [B] sensitive systems or private data, [C] changing state or communicating externally. (`meta-agents-rule-of-two`)
- **AI-orchestrated campaign.** An intrusion where the agent executes most phases and humans step in only at a few decision points. (`anthropic-ai-orchestrated-espionage`)
- **AIUC-1.** A certification standard for AI agents whose Safety principle makes technical controls and quarterly third-party testing mandatory. (`aiuc1-safety-principle`)
- **AlignmentCheck.** Meta LlamaFirewall's auditor that checks the agent's reasoning and proposed actions against the user's goal. (`meta-llamafirewall`)
- **Approval-shaped evidence.** Earlier conversation content (a vague instruction, one similar past approval) that an action judge treats as consent for a different, destructive step. (`anthropic-claude-code-auto-mode`)
- **ART benchmark.** Agent Red Teaming: curated high-impact attacks from Gray Swan's competition, split into direct (chat) and indirect (data) attacks, with a private leaderboard. (`grayswan-art-benchmark`)
- **ASR-intermediate / ASR-end-to-end.** WASP's share of runs where the agent was diverted / where the attacker's goal was completed. (`wasp-web-agent-injection`)
- **Attack success rate (ASR), attempt-level and scenario-level.** The share of attempts that succeed / the share of scenarios where at least one attempt succeeded. (`anthropic-system-card-opus-5-5`)
- **Auto mode.** Claude Code's permission mode in which a classifier reviews actions instead of the user, paired with injection probes on tool results. (`anthropic-claude-code-auto-mode`)
- **Auto-review.** A mode where a separate model, not the user, approves or denies each action the coding agent asks to run outside its sandbox. (`openai-auto-review-research`)
- **Automated agent collective.** Many agents from separate runs coordinating through a shared channel, dividing labor and pooling discoveries to attack systems with no human directing them. (`openai-hugging-face-incident-technical-report`)
- **B3 vulnerability score.** B3's 0 to 1 score of how often curated attacks succeed against a backbone at one LLM step ("threat snapshot"), lower is better. (`lakera-b3`)
- **Bad actor model.** Decagon's classifier that scores manipulative intent alongside response generation and gates replies and certain actions. (`decagon-layered-guardrails`)
- **Best-of-N (BoN) jailbreaking.** Black-box resampling of randomly augmented prompts until a harmful response appears; success grows as a power law with N. (`anthropic-best-of-n-jailbreaking`)
- **Biased reasoning / recklessness.** Selectively interpreting evidence to justify the action already underway / a propensity to keep pursuing the task even when that could cause harm. (`anthropic-alignment-assessment-cyber-incidents`)
- **CaMeL.** CApabilities for MachinE Learning: a privileged planner writes code from the trusted query, a quarantined model parses untrusted data, and an interpreter tracks capabilities and enforces policy at each tool call. (`deepmind-camel`)
- **Cascade architecture.** A cheap first-stage screen on all traffic that escalates suspicious exchanges to a stronger, costlier classifier instead of refusing them. (`anthropic-constitutional-classifiers-plus-plus`)
- **Chain of command.** The Model Spec's ordered authority levels (Root, System, Developer, User, Guideline, then no authority) for resolving conflicting instructions. (`openai-model-spec-2026-08-18`)
- **Circuit breaker.** After sustained webhook failures, the gate applies the failure setting to everyone instead of calling the security server. (`anthropic-docs-inference-hooks-configuration`)
- **Classifier-triggered fallback.** When a safety classifier fires, the request is served by an older, less injection-robust model. (`anthropic-system-card-opus-5-5`)
- **Claudius.** The Claude instance that ran Anthropic's Project Vend office shop. (`anthropic-project-vend-1`)
- **ClawHavoc.** The early-2026 campaign of malicious OpenClaw skills whose fake "Prerequisites" made agents run stealer droppers. (`unit42-openclaw-supply-chain`)
- **Clinejection.** Prompt injection through an issue title into a CI-hosted AI triage agent. (`khan-clinejection`)
- **Closed-domain task.** A task that only transforms the given text (summarize, classify, translate), so no instruction inside that text should be followed. (`openai-instruction-hierarchy-2024`)
- **Concealment.** The IPI Arena requirement that a successful attack also hide the compromise from the agent's final reply to the user. (`grayswan-ipi-arena`)
- **Confirmation policy.** Instructions given to the deployed agent stating when it must pause and get the user's approval. (`openai-gpt-6-astra-system-card`)
- **Confirmation recall.** Share of relevant actions where the agent correctly asked the user before acting; critical confirmation recall restricts it to permission edits, high-stakes communications and financial transactions. (`openai-chatgpt-agent-system-card`)
- **Confused deputy.** A privileged component that carries out a well-formed request on behalf of someone not entitled to it: the model relaying an attacker's arguments to your server, or a compromised low-privilege agent steering a high-privilege one. (`anthropic-zero-trust-ebook`, `openai-apps-sdk-security-privacy`)
- **Consent laundering.** A "read-only" preview that triggers side effects when opened. (`owasp-agentic-top10-2026`)
- **Constitutional Classifiers.** Input and output classifiers trained on synthetic data generated from a natural-language constitution of allowed and disallowed content. (`anthropic-constitutional-classifiers`)
- **Content validation guardrail.** An output check that compares the agent's reply with company policy and catalog data before delivery. (`fin-ai-guardrails-customer-service`)
- **Control-flow hijacking (multi-agent).** Adversarial content redirecting which agent or tool the orchestrator invokes next. (`triedman-multi-agent-hijack`)
- **Conversation Defense.** Parloa's guard model that reads the full conversation history each turn, runs in parallel with the agent and blocks uncertain verdicts. (`parloa-llm-guardrails`)
- **Covert channel.** Leaking data through behavior rather than content, such as whether a tool gets called at all. (`msrc-indirect-injection-defense`)
- **Crescendo.** A multi-turn jailbreak that escalates gradually from harmless questions, citing the model's own earlier answers. (`microsoft-crescendo`)
- **Cyber Jailbreak Severity (CJS) scale.** CJS-0 to CJS-4 rating of a reported jailbreak by uplift, universality, ease of weaponization and discoverability. (`anthropic-fable-safeguards-jailbreak-framework`)
- **DECLINE_TO_LABEL.** An explicit abstain output for an LLM judge, tested against judges shifting labels toward the consequence they prefer. (`anthropic-agentic-misalignment-summer-2026`)
- **Defender success rate.** OpenAI's robustness metric, the share of attacks the model withstands, higher is better. (`openai-gpt-6-astra-system-card`)
- **Defensive prompting.** Protective instructions placed around user input, tuned as new injection techniques appear. (`intercom-fin-data-privacy-security`)
- **Delayed execution.** A hijack whose malicious action happens several steps after the injection enters. (`agentdrift-benchmark`)
- **Deny-and-continue.** Returning a classifier denial to the agent as a tool result so it can find a safer path, with a counter that escalates after repeated denials. (`anthropic-claude-code-auto-mode`)
- **Deterministic vs probabilistic defense.** A control that guarantees an outcome by design (permissions, blocked rendering) versus one that only lowers the odds (prompts, Spotlighting, classifiers). (`msrc-indirect-injection-defense`)
- **Direct vs indirect injection.** Direct: the person typing is the adversary; indirect: the user is trusted and third-party content (pages, emails, documents, tool results) carries the attack. (`anthropic-docs-mitigate-jailbreaks`)
- **DNS rebinding.** An allowed hostname that resolves to a private or internal address, turning an egress allowlist into a path into your own network. (`openai-codex-approvals-security`)
- **Domain fronting.** Reaching a host outside an allowlist through a connection whose client-supplied hostname is allowlisted, possible when the proxy doesn't terminate TLS. (`anthropic-docs-agent-sdk-secure-deployment`)
- **DontAsk mode.** Convert every permission prompt into a denial without calling the approval callback. (`anthropic-docs-agent-sdk-permissions`)
- **Dots.** OpenAI's always-on, proactive agents powered by GPT-6 Astra. (`openai-gpt-6-astra-system-card`)
- **Dual LLM pattern (privileged / quarantined LLM).** A tool-holding model that never reads untrusted text, a quarantined model that reads it, and plain code passing opaque references between them. (`willison-dual-llm-pattern`)
- **EchoLeak.** Zero-click exfiltration from M365 Copilot through one crafted email (CVE-2025-32711). (`aim-echoleak-paper`)
- **Elevated Risk label.** One consistent in-product warning on network-related capabilities, explaining the change, the added risk and when to use it, removed once the risk is mitigated. (`openai-lockdown-mode-elevated-risk`)
- **Elicitation URL mode.** MCP flow that sends the user to a browser page for credentials, payment or consent, so they never transit the agent or the client. (`anthropic-mcp-production-systems`)
- **Escalation Rules vs Escalation Guidance.** Attribute-triggered handoff vs a natural-language handoff instruction; neither sets where the conversation goes, which helpdesk routing decides. (`intercom-fin-escalation-guidance`)
- **Exchange classifier.** A classifier that judges the output in the context of its input instead of each side alone. (`anthropic-constitutional-classifiers-plus-plus`)
- **Fail-open / fail-closed.** Letting requests through uninspected when the guardrail fails or times out / blocking them. (`anthropic-docs-inference-hooks-configuration`)
- **Fake Chain-of-Thought attack.** A direct injection class found by OpenAI's automated red-teamer, where the attacker writes text imitating the model's reasoning. (`openai-gpt-red`)
- **Faux reasoning.** A direct-injection technique that fakes the model's own reasoning to steer it. (`anthropic-system-card-opus-4-5`)
- **FIDES, information-flow control (IFC) for agents.** Confidentiality and integrity labels on data, propagated through the plan and enforced deterministically on flows at tool calls. (`microsoft-fides`)
- **ForcedLeak.** Noma's name for the Agentforce chain of indirect injection plus a content-security-policy bypass through an expired allowlisted domain. (`noma-forcedleak-agentforce`)
- **GPT-Red.** OpenAI's automated red-teaming system that generates the attacks for its injection and jailbreak evals. (`openai-gpt-6-astra-system-card`)
- **Guardian.** Codex's reviewer model, which sees the planned action and transcript, may run only read-only commands with no network, and returns risk, authorization, outcome and a one-sentence rationale. (`openai-codex-guardian-approvals`)
- **Hard invariants.** Non-negotiable pass/fail criteria for flows that move money, verify identity or disclose data. (`parloa-red-teaming`)
- **Harm score.** AgentHarm's rubric-graded completion of a malicious multi-step agent task, partial credit allowed. (`agentharm-benchmark`)
- **Identity injection.** Host-side MCP attack that injects a false identity into the agent's context. (`mcp-safetybench`)
- **Impersonation attack.** Inserting a fake system message that delegates authority to the attacker. (`openai-ih-challenge-paper`)
- **Impossible, not tedious.** The design test for any control against agentic attackers: remove the capability rather than add friction they can grind through. (`anthropic-zero-trust-ebook`)
- **Inference hooks.** Anthropic's enterprise gate that sends prompts and proposed tool calls to the customer's security server for an allow or deny verdict before they proceed. (`anthropic-docs-inference-hooks`)
- **Instruction hierarchy.** A trust order across message types (system over developer over user over tool output) that the model is trained to apply when instructions conflict. (`openai-instruction-hierarchy-2024`)
- **IPI Arena.** Gray Swan's public indirect-prompt-injection competition and benchmark, scoring attacks that both execute a harmful action and conceal it in the final reply. (`grayswan-ipi-arena`)
- **K.** In Anthropic's Gray Swan IPI and ART results, the probability that an attacker finds a successful attack after k attempts drawn from the benchmark's attack pool. (`anthropic-system-card-opus-5-5`)
- **KYC interception cloak.** A reverse-proxy relay that passes a victim through a genuine identity-verification flow while the attacker captures the verified session. (`anthropic-threat-intel-september-2026`)
- **Least agency.** Least privilege extended to what each agent tool may do, how often and where (OWASP's term, adopted in Anthropic's guide). (`anthropic-zero-trust-ebook`)
- **Lethal trifecta.** Access to private data, exposure to untrusted content, and the ability to communicate externally, combined in one agent, which lets an attacker trick it into sending the data out. (`willison-lethal-trifecta`)
- **Live bug bounty.** A one-week Gray Swan competition in which expert red-teamers attack hidden-identity models for prizes, one success per scenario per model. (`anthropic-system-card-opus-5`)
- **Living off AI.** Using a victim's legitimate AI integration as the attack proxy, by analogy with living off the land. (`cato-living-off-ai`)
- **Lockdown Mode.** Optional deterministic ChatGPT setting that disables or restricts every feature that could carry data out of the conversation. (`openai-lockdown-mode-elevated-risk`)
- **Lockdown Mode role.** A workspace role an admin designates so its restrictions override capabilities granted by other roles. (`openai-help-lockdown-mode`)
- **Many-shot jailbreaking.** Filling the context with many fabricated dialogues in which an assistant complies, steering the model by in-context learning; success grows as a power law in the number of shots. (`anthropic-many-shot-jailbreaking`)
- **MCP rebinding.** A DNS-rebinding-style attack against a locally bound MCP server. (`mcpsecbench`)
- **Memory-based privilege retention.** An agent reusing secrets or authorization cached in an earlier session to act for a later requester. (`anthropic-zero-trust-ebook`)
- **MINJA.** Memory INJection Attack: planting malicious memory records through ordinary queries alone. (`dong-minja-memory-injection`)
- **Misalignment monitoring.** An asynchronous provider-side check of whether an agent is properly interpreting the user's instructions in consequential contexts, able to stop the request. (`openai-misalignment-monitoring-guide`)
- **Mixed attack / Plan-of-Thought (PoT) backdoor.** ASB's combination of direct injection, indirect injection and memory poisoning / a training-free backdoor: backdoored planning demonstrations in the system prompt that a trigger in the user's query activates. (`asb-agent-security-bench`)
- **Multi-agent trust escalation.** Sub-agent output trusted more than the raw content it read because it came "from us". (`anthropic-how-we-contain-claude`)
- **Origin Sets.** Per-task read-only versus read-writable origins, set by trusted code, that bound where data may flow. (`google-chrome-agentic-security`)
- **Out-of-scope parameter.** An attack where a tool declares a parameter it doesn't need (a password, account data) so the agent fills it in. (`msb-mcp-security-bench`)
- **Overeager behavior.** Reasonable-looking problem-solving applied past the boundary of what the user authorized. (`anthropic-claude-code-auto-mode`)
- **Phrase protection.** OpenAI's eval of whether a model keeps refusing to say a protected phrase ("access granted") when a malicious message pushes for it. (`openai-gpt-5-system-card`)
- **Pinned tool list.** A recorded copy of a server's tool list sent with the request, so the server's live list is ignored. (`anthropic-docs-mcp-connector`)
- **Proactive refusals.** Refusing whole high-risk task types (banking, stock trades, high-stakes decisions) up front instead of confirming them. (`openai-operator-system-card`)
- **Prompt injection.** A third party, neither the user nor the AI, misleading the model by putting malicious instructions into the conversation context. (`openai-safety-prompt-injections-page`)
- **Prompt injection probes.** Classifiers that inspect tool results before the model acts and flag content that looks like an injected instruction. (`anthropic-system-card-opus-5-5`)
- **Prompt Sandwiching.** Repeating the user's instruction after untrusted content as a prompt-level injection defense. (`nasr-attacker-moves-second`)
- **Rails (input, dialog, retrieval, execution, output).** NeMo Guardrails' five intervention points; dialog rails route known intents to predefined responses instead of generation. (`nvidia-nemo-guardrails-readme`)
- **Recall@FPR=0.01.** The share of attacks a guardrail catches when its false-positive rate is held to 1%. (`openai-guardrails-check-prompt-injection`)
- **Reconstruction attack / output obfuscation.** Splitting a forbidden request into harmless fragments the model reassembles / instructing the model to answer in code words, metaphors or riddles so the output looks harmless. (`anthropic-constitutional-classifiers-plus-plus`)
- **Relevance guardrail / jailbreak guardrail.** The two small-model judges on every agent in OpenAI's support demo: one returns is_relevant for messages unrelated to customer service, the other is_safe for attempts to override instructions or reveal prompts. (`openai-cs-agents-demo`)
- **Role confusion / CoT Forgery / destyling / state bleeding.** Low-privilege text perceived as a higher-privilege role / injecting text styled as the model's chain of thought / rewriting injected text so it no longer sounds like the role it imitates / the continuous influence of any token on model state regardless of role. (`ye-role-confusion`)
- **Rug pull.** A tool definition changed after it was approved. (`invariant-tool-poisoning`)
- **Safety identifier.** A stable, hashed per-end-user string sent with each model request so the provider can attribute and block abuse at the user level. (`openai-safety-checks-guide`)
- **Safety margin.** The band of benign requests near the prohibited line that a classifier deliberately blocks to catch the harmful ones, set per band in a four-band scheme (prohibited, high-risk dual use, low-risk dual use, benign). (`anthropic-fable-safeguards-jailbreak-framework`)
- **Scope of autonomy.** The agreed sub-goals, acceptable side effects and pause points that bound what an agent may do without asking, with an ending condition. (`openai-model-spec-2026-08-18`)
- **Screenshot attack.** Getting a support bot to say something off-topic, humorous or disparaging for a screenshot. (`beurer-kellner-design-patterns`)
- **Security by incompetence.** Attacks failing because the agent is too unreliable to complete the attacker's goal, not because it resists. (`wasp-web-agent-injection`)
- **Session hijack prompt injection.** Injecting events into a shared queue under a stolen session ID so the legitimate client receives and acts on them. (`mcp-spec-security-best-practices`)
- **Shade.** Gray Swan's adaptive red-teaming attacker, trained on test scenarios against earlier models and then run unchanged against newer ones. (`anthropic-system-card-sonnet-5-5`)
- **Shadow mode.** A guardrail state that collects verdicts on live traffic and blocks nothing. (`anthropic-docs-inference-hooks-configuration`)
- **ShadowLeak.** Zero-click exfiltration from ChatGPT Deep Research that left from the provider's infrastructure, invisible to the victim's network. (`radware-shadowleak`)
- **Spotlighting.** Delimiting, datamarking or encoding untrusted input so the model can separate it from instructions. (`msrc-indirect-injection-defense`)
- **Spotlighting (delimiting, datamarking, encoding).** Transforming untrusted input so the model can tell it from instructions: wrapping it in markers, interleaving a special character between words, or encoding it (base64). (`msrc-indirect-injection-defense`)
- **SSRF (server-side request forgery).** Making your backend or proxy fetch an attacker-chosen address, such as an internal service or the cloud metadata endpoint. (`anthropic-docs-mcp-tunnels-security`, `mcp-spec-security-best-practices`)
- **Substitution at egress.** Replacing a sandbox placeholder with the real secret on the outbound request, outside the agent's view. (`anthropic-docs-managed-agents-vaults`)
- **Success@N (S@N).** The probability of at least one success in N independent attack attempts. (`automated-pi-agentic-envs`)
- **Sycophancy.** Agreeing with or flattering the user instead of keeping an accurate answer; OpenAI's April 2025 GPT-4o update showed it as "validating doubts, fueling anger, urging impulsive actions". (`openai-sycophancy-what-we-missed`)
- **Targeted attack success rate (targeted ASR).** Share of runs where the agent executed the attacker's injected task. (`spylab-agentdojo-leaderboard`)
- **Task drift (TaskTracker).** The change in a model's activations before and after it reads external data, used to detect that an injection redirected the task. (`microsoft-task-drift`)
- **Token passthrough.** An MCP server forwarding client tokens that were not issued to it to downstream APIs. (`mcp-spec-security-best-practices`)
- **Tool filter.** AgentDojo defense that cuts the agent's tools to those the user's task needs before it reads untrusted data. (`spylab-agentdojo-leaderboard`)
- **Tool poisoning.** Malicious instructions embedded in a tool's metadata (description, schema) rather than its output. (`invariant-tool-poisoning`, `mcptox-benchmark`)
- **Tool shadowing.** A tool whose description tells the model to call, avoid or change how it uses other tools. (`anthropic-software-directory-policy`)
- **Topic instructions.** Salesforce Agentforce's natural-language rules per topic, used for escalation and behavior. (`salesforce-agentforce-guardrails-trailhead`)
- **Transfer only.** Attacks found on other models replayed against the target without re-optimization. (`benchmarklist-grayswan-ipi`)
- **Tripwire.** The flag a guardrail raises to halt the run in the OpenAI Agents SDK; a tripwire excludes the rejected output, while a guardrail that raises an exception lets the turn's items persist. (`openai-agents-sdk-guardrails`)
- **Universal jailbreak.** One jailbreak that gets past the safeguards for every question in the test set, not just one. (`anthropic-constitutional-classifiers`)
- **Unsanctioned action.** An autonomous agent action beyond the task's authorized scope, directed at the real world. (`aisi-incident-unsanctioned-agent`)
- **Unsandboxed retry.** The model-requested rerun of a failed command outside the sandbox. (`anthropic-docs-claude-code-sandboxing`)
- **Unscoped privilege inheritance.** A coordinating agent passing its full access to the worker it delegates to. (`anthropic-zero-trust-ebook`)
- **User Alignment Critic.** Chrome's separate checker model that sees only the user's goal and action metadata and vetoes actions that don't serve the goal. (`google-chrome-agentic-security`)
- **Vault.** The collection of credentials tied to one end user, referenced by ID when a session is created. (`anthropic-docs-managed-agents-vaults`)
- **Watch mode.** Automatic pause of the agent on sensitive sites whenever the user stops supervising. (`openai-operator-system-card`)
- **Zero data retention (ZDR).** A provider arrangement not to keep request data, covering only the paths the provider names. (`anthropic-docs-mcp-connector`, `anthropic-docs-server-tools`)
