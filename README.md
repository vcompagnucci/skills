# skills

Skills I build to get more out of my own work, from building AI agents to designing apps. Models half-remember the details, so each skill holds what the sources actually say and cites every claim.

## Install

```bash
npx skills@latest add vcompagnucci/skills
```

## Agents

- **[claude-agents](./claude-agents/SKILL.md).** Building an agent the Anthropic way. 124 sources.
- **[openai-agents](./openai-agents/SKILL.md).** The same for OpenAI, Codex harness included, on the same 10 topics. 130 sources.
- **[agent-harness](./agent-harness/SKILL.md).** The loop, tools, state and human handoffs around any agent, and when to buy one instead.
- **[agent-evals](./agent-evals/SKILL.md).** Evals from the first traces to production, on Hamel Husain and Shreya Shankar's method.
- **[agent-security](./agent-security/SKILL.md).** Keeping an agent that reads untrusted text and calls tools from being turned against its users. 312 sources.
